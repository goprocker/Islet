Installed in three steps

  1. Download

    Grab Islet-Setup-2.3.1.exe with the button above.

  2. Run it

    It adds a Start menu entry and installs to your user folder. No admin rights needed.

  3. Meet the notch

    Islet appears at the top of your screen. Updates install themselves when you quit.

If Windows warns you

SmartScreen

The installer is unsigned, so SmartScreen may show a warning. Choose More info, then Run anyway.

Smart App Control

If Smart App Control blocks it, the installer can't run on that PC. Run Islet from source instead: github.com/goprocker/Islet.

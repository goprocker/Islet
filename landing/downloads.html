Install

  1. Run the downloaded file. It adds a Start menu entry and installs to your user folder, with no admin rights needed.
  2. The installer is unsigned. If SmartScreen warns you, choose More info, then Run anyway.
  3. If Smart App Control blocks it, the installer can't run on that PC. Run Islet from source instead: github.com/goprocker/Islet.

Islet checks GitHub for updates and installs them when you quit. See the Privacy Policy.

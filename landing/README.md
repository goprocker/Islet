# Islet landing page

## Demo song

The player tries `radhimaa-loop.mp3` first. That song is commercial music, so it is deliberately not in this public repo, and a clean checkout doesn't have it.

Without it, the player uses `demo-loop.mp3`, a 32-second cut of the launch film's score. That score is generated by `launch-film/scripts/make_score_apple.py`, so a Git deploy always has sound. If neither file loads, the player says "Demo audio unavailable" and the play button is off.

To deploy with the commercial song, you must have the right to publish it. Put the file at `landing/radhimaa-loop.mp3`, then deploy from `landing`.

# Islet landing page

## Demo song

The page plays `radhimaa-loop.mp3`. The song is commercial music, so it is deliberately not in this public repo, and a clean checkout doesn't have it. Without it the page still works: the player says "Demo audio unavailable" and the play button is off.

To deploy with sound, you must have the right to publish the song. Put the file at `landing/radhimaa-loop.mp3`, then deploy from `landing`. Afterwards, check that `/radhimaa-loop.mp3` returns audio on the live site.
